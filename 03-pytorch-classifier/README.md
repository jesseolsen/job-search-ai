# PyTorch Classifier

A text classification model that identifies resume sections (EXPERIENCE, EDUCATION, SKILLS, PROJECTS, SUMMARY, OTHER). Uses PyTorch for flexible model architecture and training pipelines.

## Features

- **Custom `Dataset` and `DataLoader`**: Load labeled resume snippets
- **`TextClassifier` model**: Embedding layer → LSTM → softmax
- **Full training loop**: Forward pass, loss, backprop, optimizer step
- **Validation with metrics**: Track accuracy, precision, recall
- **Model persistence**: Save/load with `torch.save` / `torch.load`
- **Inference function**: `predict(text: str) -> str`

## Key Concepts

### Custom Dataset

```python
from torch.utils.data import Dataset, DataLoader

class ResumeDataset(Dataset):
    def __init__(self, texts, labels, vocab):
        self.texts = texts
        self.labels = labels
        self.vocab = vocab
    
    def __len__(self):
        return len(self.texts)
    
    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]
        # Convert text to token indices
        tokens = [self.vocab.get(w, 0) for w in text.lower().split()]
        return torch.tensor(tokens), torch.tensor(label)
```

## Dataset

The training data is synthetic, generated by `generate_data.py`:
- ~500-1000 labeled examples
- Known patterns per section (degree names → EDUCATION, job titles → EXPERIENCE, etc.)
- Split: 80% train, 20% validation

**Target accuracy**: ≥70% on validation set. The goal is understanding PyTorch, not achieving perfect accuracy.
